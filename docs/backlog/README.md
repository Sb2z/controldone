# Améliorations repérées en cours de route

Chaque bloc de travail consigne ici, dans son propre fichier, ce qu'il remarque sans le traiter : défaut hors de son
périmètre, idée d'amélioration, dette technique, risque. Une entrée : **titre**, constat (avec fichier ou mesure),
impact, proposition, et « fait » ou « à faire ». L'orchestrateur consolide dans `docs/A_FAIRE.md`.

| Fichier | Bloc |
|---|---|
| `moteur.md` | totaux par code de taxe, bruit « à vérifier », rappel |
| `securite.md` | limitation de débit, dépendances, en-têtes, revue de sécurité |
| `sauvegardes.md` | sauvegarde et restauration |
| `interface.md` | recherche, filtres, pagination, suivi en direct |
| `orchestrateur.md` | constats transverses |
| `outillage.md` | vérifications avant enregistrement, couverture, tests de propriétés, corpus non versionnés |
| `production.md` | fiabilité de la production : PostgreSQL, alertes poussées, migrations, verrou de maintenance |
